# hasansharifian.github.io

Personal academic website of MohammadHasan (Hasan) Sharifian, live at
https://hasansharifian.github.io.

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## Where things are

- `_pages/` – the pages: `about.md` (home), `projects.md`, `cv.md`, `404.md`
- `assets/img/photo.jpg` – profile photo
- `assets/icons/` – project icons
- `assets/pdf/` – CV
- `_config.yml` – site settings

Pushing to `main` rebuilds and publishes the site automatically
(`.github/workflows/deploy.yml`).
